# REFLEX — быстрый старт

## A. Погонять тестовый полигон (всё в Docker, ничего не меняя)

```bash
cd ~/Work/reflex
docker compose build
docker compose up -d                 # поднять всё: геймсервер, боксы, атакующих, REFLEX
docker compose logs -f reflex        # смотреть контр-удары и выученные паттерны
docker compose down                  # снести
```

Счёт в любой момент:
```bash
docker compose exec gameserver wget -qO- http://127.0.0.1/scoreboard
```

## B. Запуск на своём вулнбоксе (в реальной игре)

Нужен только `python3` (ничего ставить не надо) и запуск от root (нужен сырой сокет).

**1. Настройка — всего 3 значения:**

| Переменная | Что это | Пример |
|------------|---------|--------|
| `SELF_IP`  | IP твоего вулнбокса в игровой сети | `10.60.13.1` |
| `GS`       | адрес геймсервера (куда сдавать флаги / брать flag-id) | `10.60.254.1` |
| `IFACE`    | сетевой интерфейс вулнбокса | `eth0` |

Номер команды и схема сети вычисляются из `SELF_IP` сами.
Формат флага по умолчанию уже `uralcup{...}` — менять не надо.

Необязательные (есть разумные дефолты):

| Переменная | Что это | Дефолт |
|------------|---------|--------|
| `TARGET_MODE` | по кому бить: `vulnbox` (10.60.N.1), `source` (ровно адрес атакующего), `both` (сперва вулнбокс, потом источник) | `both` |
| `FLAG_FORMAT` | регулярка флага, если лига не uralcup | `uralcup\{[^}]{1,80}\}` |
| `VICTIM_PORT` | порт сервиса у жертвы | = порт твоего |

**Куда он бьёт — видно в логе.** На каждый удар пишется
`attack_from` (откуда тебя ударили) → `hit_target` (куда ударил REFLEX) →
`tried_targets`. Режим `both` гарантирует попадание: пробует вулнбокс команды, затем
ровно тот IP, с которого атаковали, и берёт первый, что реально отдал флаг.

**Рабочие эксплойты сохраняются.** При каждой успешной сдаче флага эксплойт
(шаблон запроса + техника + стратегия) пишется в `/var/log/reflex_exploits.jsonl` —
один раз на паттерн. Это твой арсенал: что реально пробивает соперников.

**2. Запуск:**

```bash
sudo SELF_IP=10.60.13.1 GS=10.60.254.1 IFACE=eth0 python3 reflex/reflex.py
```

В фоне, с логом в файл:
```bash
sudo SELF_IP=10.60.13.1 GS=10.60.254.1 IFACE=eth0 \
  nohup python3 reflex/reflex.py > reflex.out 2>&1 &
tail -f reflex.out
```

Остановить:
```bash
sudo pkill -f reflex.py
```

## Что увидишь в логе

- `learned_pattern` — REFLEX сам выучил форму эксплойта (idor / sqli / lfi / php).
- `counterstrike ... verdict=ACCEPTED` — отбил флаг у атакующего и сдал его.
- `intel ...` — кто чем тебя щупает (в т.ч. xss), без контрудара.
- `[stats]` — счётчики (каждые 5с).

## Если что-то не так

- **Нет контр-ударов** — проверь, что `SELF_IP` и `IFACE` реально твои (`ip a`),
  и что запущено от `sudo`.
- **`bind_fail` в логе** — не тот интерфейс в `IFACE`.
- **`flagid_fail` / `submit_fail`** — не тот адрес `GS` или другой API у лиги
  (правится вверху `reflex/reflex.py`).
